Welcome

This site is a work in progress.
If any bugs or issues occur, make sure to run the website in a "fresh" browser instance by opening it in a private/incognito window.
The site is currently only being tested in the lastest version of Google Chrome, but it should normally work without issues on other common browsers.
Make sure to also refresh the webpage whenever serious issues occur with the score rendering.

Use the navigation bar at the top to find scenes from the opera that you wish to view. The website currently supports Acts 1 and 2 of the 1906 version (without lyrics and text!).
The "sandbox" section showcases the most advanced version of the score viewer using a single scene as a test case. This scene supports both the 1906 and 1909 versions.
